# Scripts do Banco de Dados

Scripts SQL utilizados para criação, carga inicial e validação do banco de dados do projeto SURTE.

## Estrutura

| Arquivo | Descrição |
|----------|------------|
| script-create.sql | Criação das tabelas e estruturas |
| script-insert.sql | Dados iniciais para testes |
| script-consultas.sql | Consultas de validação e exemplos |

## Ordem de execução

1. script-create.sql
2. script-insert.sql
3. script-consultas.sql

## Banco de dados

PostgreSQL

## Observações

Os scripts são destinados ao ambiente de desenvolvimento e homologação.
